# دليل الطالب

1. افتح محادثة **خاصة** مع البوت، ولا تؤدِّ الامتحان داخل مجموعة مشتركة.
2. أرسل `/start` لبدء الامتحان.
3. أرسل إجابة واحدة لكل سؤال، وانتظر السؤال التالي قبل إرسال إجابة أخرى.
4. بعد آخر سؤال، انتظر رسالة التقييم والنتيجة النهائية.
5. إرسال `/start` مرة أخرى يعيد بدء محاولتك وقد يستبدل تقدم المحاولة الحالية. لا تستخدمه أثناء الامتحان إلا إذا أردت البدء من جديد.
6. إذا لم يصل السؤال التالي أو النتيجة، لا تكرر الرسائل بسرعة؛ أخبر مشرف الامتحان بوقت المحاولة واسم المستخدم فقط. لا ترسل إجاباتك في مجموعة عامة أو في بلاغ GitHub.
